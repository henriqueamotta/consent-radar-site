# Consent Radar — site público

Site institucional da extensão [Consent Radar](https://github.com/henriqueamotta/consent-radar) para o Google
Chrome. Publicado em https://henriqueamotta.github.io/consent-radar-site/

## Páginas

- `index.html` — apresentação do produto.
- `privacy.html` — política de privacidade da extensão (exigida pela Chrome Web Store).
- `pro.html` — lista de espera do recurso Pro.

## Stack

HTML + CSS puros, sem build e sem framework. Fontes do sistema, sem analytics nem CDNs. O único terceiro
incorporado é o formulário da [Tally](https://tally.so), na página Pro.

Ver `CLAUDE.md` para as convenções do projeto.
